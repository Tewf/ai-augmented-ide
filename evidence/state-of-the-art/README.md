# State of the art: open editor extensions that drive a coding agent

The review behind this repository, a first pass run on 2026-11-02. It asks which open VS Code extensions already do part of the method, what the studies say about supervising coding agents, and which extension is the baseline.

- It holds 28 sources: 12 repositories read by metadata or in source, and 16 preprints read by abstract.
- Three open extensions were read in source: Cline, Continue and Kilo Code. Two archived ones were not.
- None of the three shows a tree of topics or a verdict beside what it checked.
- The baseline is Kilo Code, MIT. The position is beside all.
